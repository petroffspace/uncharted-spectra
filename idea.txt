My idea is: there is some limited spectre where all the music, people talking, sounds of nature, all people hear and understand reside. Theoretically all other spectre is chaos white noise. But what if we have uncharted territories, where sounds reside that people never heard. What kind of program I want. Build on Go engine server and web ui. From web I upload some bmp or wav. After uploading I have two boxes left is a generated waveform image and right is if it's bmp upload - the image iploaded and if it was wav image produced by wav2bmp. Above these two boxes Play/Stop button resides what it does plays the wav file, when playing button changes to stop and stops audio play on click. Then I need 3 rotary controllers that changes wav2bmp image what they do is 1st: is scroll left/right so each scroll replacing one line of pixels 1x width and down number of pixels equal to the image height, they pixel values are taken from /dev/urandom, 2nd The same functionality but scroll top and bottom. 3rd randomize image with similar random pixels from /dev/urandom. Also to have button Scan: what it does scan /dev/urandom for the point current upload is to find something then sounds not like white noise, when found - it stops scan. That's the core. System architecture is core + modules based. Modules are sound or image manipulation filters. So for sound at the start we can get ladspa plugins. For sound manipulation we use graphics plugins: standard brightness/contrast, levels, gaussian blur, fill the rest with most used image manipulation plugins. And for image manipulation we use sound filters. When choosing filter we adjust it's settings in modal, then click apply. Aplied filter updates wav or bmp so we can then press play to listen result. After applying filter we can undo changes. This is the base for alpha version.
